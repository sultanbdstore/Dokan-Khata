📘 ইউজার ম্যানেজমেন্ট সেটআপ গাইড (একদম নতুনদের জন্য)

এটি দিয়ে কী হবে: আপনার বন্ধুরা অ্যাপ চালালে আপনি দেখতে পাবেন কে কে ব্যবহার করছে। দরকারে কাউকে হোল্ড (সাময়িক বন্ধ) করতে পারবেন, আবার চালুও করতে পারবেন। সব বিনামূল্যে।

যা লাগবে: একটি Gmail অ্যাকাউন্ট, একটি কম্পিউটার (সহজ হয়), আর প্রায় ১৫ মিনিট। কম্পিউটার না থাকলে ফোনের Chrome-এ ⋮ মেনু থেকে Desktop site টিক দিয়ে করা যায়, তবে কিছুটা কঠিন।

হিসাবের ডাটা এখানে আসে না। শুধু প্রতিটি ইউজারের দোকানের নাম, মালিকের নাম, মোবাইল আর কখন অ্যাপ খুলেছে, এটুকু আসে।

ধাপ ১: Google Sheet বানান

  1. Chrome-এ https://sheets.google.com খুলুন এবং আপনার Gmail দিয়ে ঢুকুন।
  2. Blank spreadsheet (খালি ফাইল) চাপুন।
  3. উপরের বাঁদিকে "Untitled spreadsheet" লেখায় চেপে নাম দিন: Dokan Khata Users।

ধাপ ২: Apps Script খুলুন

  1. Sheet-এর উপরের মেনু থেকে Extensions চাপুন, তারপর Apps Script।
  2. নতুন একটি ট্যাব খুলবে। ভেতরে function myFunction() { } লেখা একটি ঘর দেখবেন। এটিই কোডের ঘর।

ধাপ ৩: কোড বসান

  1. কোডের ঘরের ভেতরে ক্লিক করুন। Ctrl + A চেপে সব সিলেক্ট করে Delete চাপুন, ঘর খালি হয়ে যাবে।
  2. zip-এর ভেতরের apps-script/Code.gs ফাইলটি খুলুন (Notepad বা যেকোনো টেক্সট অ্যাপে)। সব কোড কপি করে (Ctrl + A, Ctrl + C) ওই ঘরে পেস্ট করুন (Ctrl + V)। ADMIN_GUIDE.html খুললে কোডের পাশে একটি কপি বোতামও পাবেন।
  3. কোডের ২ নম্বর লাইনে ChangeThisSecret123 মুছে নিজের একটি গোপন পাসওয়ার্ড লিখুন। একক উদ্ধৃতি চিহ্ন ' ' বদলাবেন না, শুধু ভেতরের লেখা বদলান।
    • ইংরেজি অক্ষর ও সংখ্যা দিন, স্পেস দেবেন না, কমপক্ষে ৮ অক্ষর।
    • উদাহরণ: const KEY = 'Sultan@Khata2026';
    • এই পাসওয়ার্ড কাগজে লিখে রাখুন। পরে অ্যাডমিন পাতায় লাগবে। কাউকে বলবেন না।
  4. উপরের 💾 Save project (সেভ) আইকনে চাপুন, অথবা Ctrl + S।
  5. উপরের বাঁদিকে "Untitled project" লেখায় চেপে নাম দিন DokanKhataServer।

ধাপ ৪: Deploy (ইন্টারনেটে চালু করা)

  1. উপরের ডানদিকে নীল Deploy বোতামে চাপুন, তারপর New deployment।
  2. "Select type" এর পাশের ⚙️ গিয়ার আইকনে চাপুন এবং Web app বাছুন।
  3. নিচের ঘরগুলো এভাবে ভরুন:
    • Description: v1
    • Execute as: Me (আপনার ইমেইল)
    • Who has access: Anyone (অবশ্যই "Anyone", অন্য কিছু নয়)
  4. Deploy চাপুন।
  5. "Authorize access" লেখা আসবে। Authorize access চাপুন, আপনার Gmail বাছুন। "Google hasn't verified this app" সতর্কতা এলে ঘাবড়াবেন না, এটি আপনার নিজের বানানো স্ক্রিপ্ট। Advanced চাপুন, তারপর Go to DokanKhataServer (unsafe), তারপর Allow।
  6. শেষে Web app URL আসবে, দেখতে এমন: https://script.google.com/macros/s/AKfy.../exec। এর পাশের Copy চাপুন এবং কোথাও লিখে রাখুন। হারিয়ে গেলে Deploy → Manage deployments থেকে আবার পাবেন।

ধাপ ৫: পরীক্ষা করুন (সার্ভার চলছে কি না)

  1. কপি করা URL ব্রাউজারের নতুন ট্যাবে খুলুন। দেখাবে: {"ok":1,"message":"দোকান খাতা সার্ভার চালু আছে"}। দেখালে সফল।
  2. এবার URL-এর শেষে এই লেখা জুড়ে খুলুন (URL-এর পরেই, স্পেস ছাড়া):
    ?action=ping&id=test12345678&shop=Test&owner=Me&phone=017
    দেখাবে: {"status":"active","msg":""}।
  3. Google Sheet-এ ফিরে যান। নিচে Users নামে নতুন একটি ট্যাব দেখবেন, তাতে Test নামে একটি সারি। এর মানে সব ঠিক। সারিটির নম্বরে ডান-ক্লিক করে Delete row দিয়ে মুছে দিন।

ধাপ ৬: অ্যাপে URL বসান

  1. GitHub-এ আপনার dokan-khata repo খুলুন এবং config.js ফাইলটিতে চাপুন।
  2. ডানদিকের ✏️ (Edit) আইকনে চাপুন।
  3. scriptUrl: '' এর দুটি উদ্ধৃতি চিহ্নের মাঝখানে কপি করা URL পেস্ট করুন:
    scriptUrl: 'https://script.google.com/macros/s/AKfy.../exec'
  4. উপরের ডানদিকে সবুজ Commit changes… চাপুন এবং আবার Commit changes চাপুন।
  5. ১–২ মিনিট অপেক্ষা করুন।

ধাপ ৭: নিজে পরীক্ষা করুন

  1. অ্যাপের লিংক খুলুন (নতুন ব্রাউজার বা Incognito ট্যাবে, যাতে আপনার আগের ডাটা না আসে)।
  2. স্বাগতম পর্দায় দোকানের নাম ইত্যাদি দিয়ে শুরু করুন।
  3. Google Sheet-এর Users ট্যাবে নতুন একটি সারি এসেছে কি না দেখুন। এলে ইউজার ট্র্যাকিং কাজ করছে।

ধাপ ৮: অ্যাডমিন পাতা ব্যবহার করুন

  1. এই ঠিকানা খুলুন: https://আপনার-ইউজারনেম.github.io/dokan-khata/admin.html
  2. ধাপ ৩-এ দেওয়া পাসওয়ার্ড (KEY) লিখে লোড করুন চাপুন।
  3. প্রতিটি ইউজারের কার্ডে দোকান, নাম, মোবাইল, কবে যোগ দিয়েছে আর শেষ কবে খুলেছে দেখা যাবে।
  4. ⏸ হোল্ড করুন চাপলে বার্তা লিখতে বলবে। বার্তা দিলে ওই ইউজারের অ্যাপ বন্ধ হয়ে বার্তাটি দেখাবে।
  5. ▶ চালু করুন চাপলে ইউজার ইন্টারনেটসহ অ্যাপ খুললেই আবার চলবে।
  6. বিকল্প: Google Sheet-এর Status ঘরে সরাসরি hold বা active লিখলেও একই কাজ হয়।

ধাপ ৯: বন্ধুদের পাঠানোর মেসেজ (হোয়াটসঅ্যাপে কপি করুন)

আমার বানানো দোকান খাতা অ্যাপ: https://আপনার-ইউজারনেম.github.io/dokan-khata/
১. লিংকটি Chrome-এ খুলুন। ২. ⋮ মেনু → Install app। ৩. অ্যাপ খুলে আপনার দোকানের নাম, লোগো ও মোবাইল দিয়ে শুরু করুন। আপনার হিসাব শুধু আপনার ফোনেই থাকবে। সপ্তাহে একবার ⚙️ → ব্যাকআপ নেবেন।

সমস্যা হলে

সমস্যাসমাধান
অ্যাডমিন পাতায় "ভুল পাসওয়ার্ড"Code.gs-এর KEY আর পাতায় দেওয়া পাসওয়ার্ড হুবহু মিলতে হবে (বড়-ছোট হাতের অক্ষরও)
Sheet-এ নতুন ইউজার আসছে নাscriptUrl ঠিক আছে কি দেখুন (শেষে /exec থাকবে)। Deploy-এ "Who has access" Anyone কি না দেখুন। ইউজারের ফোনে ইন্টারনেট আছে কি না দেখুন
Code.gs বদলানোর পরেও আগের মতো চলছেDeploy → Manage deployments → ✏️ → Version: New version → Deploy (URL একই থাকবে)
"Authorization required" লেখা আসছেধাপ ৪-এর ৫ নম্বরের মতো আবার Allow দিন
হোল্ড করলেও ইউজার অ্যাপ চালাচ্ছেইউজারের ফোনে একবার ইন্টারনেট চালু করে অ্যাপ খুলতে হবে। ইন্টারনেট ছাড়া অ্যাপ শেষ জানা অবস্থায় চলে

নিরাপত্তা

  • KEY কাউকে দেবেন না। admin.html খোলা থাকলেও KEY ছাড়া ইউজার তালিকা বা হোল্ড করা যায় না।
  • repo যদি Public হয়, তবে scriptUrl সবাই দেখতে পাবে। এতে কেউ ইউজার তালিকা দেখতে বা হোল্ড করতে পারবে না, তবে ভুয়া নাম ঢোকানোর চেষ্টা করতে পারে। বন্ধুদের মধ্যে ব্যবহারে এটি সমস্যা নয়।
  • প্রযুক্তি জানা কেউ চাইলে ব্রাউজার থেকে এই হোল্ড এড়াতে পারে। বন্ধুদের মধ্যে ব্যবহারের জন্য এটি যথেষ্ট।

📋 Code.gs (ধাপ ৩-এর কোড)

// দোকান খাতা – ইউজার ম্যানেজমেন্ট (Google Apps Script)
const KEY = 'ChangeThisSecret123';   // <-- এখানে নিজের গোপন পাসওয়ার্ড লিখুন (ইংরেজি অক্ষর/সংখ্যা, স্পেস ছাড়া)
const SHEET = 'Users';
function sh_() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let s = ss.getSheetByName(SHEET);
  if (!s) { s = ss.insertSheet(SHEET); s.appendRow(['ID','Shop','Owner','Phone','Registered','LastSeen','Status','Message','Version','Logo']); }
  if (!s.getRange(1, 10).getValue()) s.getRange(1, 10).setValue('Logo');
  s.getRange('D:D').setNumberFormat('@');
  return s;
}
function out_(o) { return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON); }
function row_(s, id) { const v = s.getDataRange().getValues(); for (let i = 1; i < v.length; i++) if (String(v[i][0]) === String(id)) return i + 1; return 0; }
function clip_(v, n) { return String(v || '').slice(0, n); }
function doGet(e) {
  const p = e.parameter || {}, a = p.action;
  if (!a) return out_({ ok: 1, message: 'দোকান খাতা সার্ভার চালু আছে' });
  const lock = LockService.getScriptLock(); lock.waitLock(10000);
  try {
    const s = sh_(), now = new Date();
    if (a === 'ping') {
      if (!/^[a-z0-9]{10,40}$/.test(p.id || '')) return out_({ status: 'active', msg: '' });
      const shop = clip_(p.shop, 60), owner = clip_(p.owner, 60), phone = clip_(p.phone, 20), ver = clip_(p.v, 5);
      const logo = /^data:image\/jpeg;base64,[A-Za-z0-9+\/=]{20,6000}$/.test(p.logo || '') ? p.logo : '';
      const r = row_(s, p.id);
      if (!r) { s.appendRow([p.id, shop, owner, phone, now, now, 'active', '', ver, logo]); return out_({ status: 'active', msg: '' }); }
      s.getRange(r, 2, 1, 3).setValues([[shop, owner, phone]]);
      s.getRange(r, 6).setValue(now); s.getRange(r, 9).setValue(ver);
      if (logo) s.getRange(r, 10).setValue(logo);
      const v = s.getRange(r, 7, 1, 2).getValues()[0];
      return out_({ status: v[0] === 'hold' ? 'hold' : 'active', msg: v[1] || '' });
    }
    if (p.key !== KEY) return out_({ error: 'unauthorized' });
    if (a === 'list') {
      const v = s.getDataRange().getValues().slice(1).map(x => ({ id: x[0], shop: x[1], owner: x[2], phone: x[3], reg: x[4], seen: x[5], status: x[6], msg: x[7], v: x[8], logo: x[9] }));
      return out_({ users: v });
    }
    if (a === 'set') { const r = row_(s, p.id); if (!r) return out_({ error: 'not found' }); s.getRange(r, 7, 1, 2).setValues([[p.status === 'hold' ? 'hold' : 'active', clip_(p.msg, 200)]]); return out_({ ok: 1 }); }
    if (a === 'del') { const r = row_(s, p.id); if (r) s.deleteRow(r); return out_({ ok: 1 }); }
    return out_({ error: 'bad request' });
  } finally { lock.releaseLock(); }
}
